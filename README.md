# 时间笔记

一个面向个人的时间记录工具，在手机和电脑浏览器中使用。记录时间与备注，回看统计，也可以按需启用 GitHub Gist 云端记录、留言弹幕和 AI 分析。

项目采用 HTML、CSS 和 JavaScript 的静态多页面结构，可部署到 GitHub Pages。本地记录无需配置账号；主页支持完成首次准备后的离线使用。

[打开主页](https://su-drachen.github.io/timer/pagemain.html) · [打开入口](https://su-drachen.github.io/timer/)

## 功能

- **本地记录**：新增时间与备注，编辑、删除、CSV 导入导出，查看次数与月度趋势。
- **云端记录**：通过自己的 GitHub Gist 读取、保存和管理记录。
- **留言与弹幕**：留言 Gist ID 选填，支持读取、回复及已加载留言的弹幕播放，无自动轮询。
- **个人观察书桌**：用日历回看云端记录，筛选日期，查看和回复纸条。
- **辅助页面**：词条统计、成就徽章、数据修复、时长分析及 AI 顾问。
- **离线主页**：预缓存主页所需的样式、图标和图表资源，断网后仍能操作本地记录。
- **手机操作**：主要按钮扩大触控区域，弹窗适配键盘后的可见空间并保留背景滚动位置；“极简白”使用黑白灰配色。

## 开始使用

### 只用本地记录

1. 打开主页，选择“本地记录”。
2. 点击“记录这一刻”，填写可选备注并保存。
3. 在记录列表中编辑、删除或导出 CSV。

记录保存在当前浏览器的 `localStorage` 中。不同设备、浏览器或站点来源（协议、域名、端口）的数据彼此独立；同一来源下的不同页面共享存储。清除网站数据会清除本地记录，建议保留 CSV 备份。

**本地记录与云端记录是两份独立数据。** 恢复联网不会自动上传本地记录，也不会自动把手机与电脑的本地列表合并。

### 配置云端记录

在自己的 GitHub 账户中准备一个 Gist，添加 `records.json` 文件。没有历史记录时，内容填写：

```json
[]
```

已有记录采用以下格式；这里只是虚构示例：

```json
[
  {
    "time": "2026/10/26 08:00:00",
    "remark": "开始阅读"
  }
]
```

在主页“云端同步”的配置窗口填写：

| 配置项 | 是否必填 | 说明 |
| --- | --- | --- |
| GitHub 用户名 | 启用云端时必填 | Gist 所属账户 |
| 主 Gist ID | 启用云端时必填 | 存放 `records.json` 的 Gist |
| PAT | 启用云端时必填 | 具备对应 Gist 访问与写入权限的个人访问令牌 |
| 留言 Gist ID | 选填 | 留空时不开启留言，不影响打卡 |

真实配置通过页面输入，不要写入源文件、README 或提交记录。配置保存在当前浏览器，换设备后需要重新配置。

### 留言与作者身份

- 主页留言只在进入主页或手动点击“刷新留言”时读取。
- 保存新的留言配置后，手动刷新留言或重新进入主页即可加载。
- 回复通过 Gist 评论接口写入；还兼容读取旧的 `Interaction.json` 纸条数据。
- 弹幕重播使用已加载的留言，不会因为播放动画而重复请求网络。
- 认证作者操作需要导入与当前验签公钥匹配的作者钥匙。作者昵称和通过签名验证的作者身份是不同的状态。

作者钥匙包含私密信息，只在自己的可信设备中导入，不随项目发布。原 `see/` 子项目保留在本机，不属于本仓库的发布内容。

### AI 配置

在 `page5.html` 的“清言 API 设置”中填写 API Key、API Secret 和 Assistant ID。该功能需要联网，并依赖相应服务的可用性。

主动使用记录分析时，记录摘要及备注等内容会发往第三方 AI 服务；这部分不是本地计算。分析结果用于参考，不能作为健康诊断。

## 离线使用

1. 先联网打开 `pagemain.html`，等待顶部出现 **“离线已就绪”**。
2. 此后在同一浏览器中，断网也可以重新打开入口或主页。
3. 本地记录的查看、新增、编辑、删除、CSV 导入导出和主页图表可继续使用。

离线支持的范围是**入口、主页及本地记录功能**。其他页面、Gist 同步、留言、AI 和外部链接仍需要网络。入口的外部图片与搜索服务也不在离线保证范围内。

- 首次从未访问过的设备，需要联网完成一次准备。
- 直接双击 HTML 文件产生的 `file://` 地址不支持此离线启动流程；请通过 HTTPS 网站或开发机的 `localhost` 访问。
- 离线资源缓存不是记录备份。清除网站数据会同时影响本地记录和缓存。
- 缓存缺失时，可联网点击“重试准备”。
- 新版本不会强制刷新正在编辑的页面。提示新版已准备后，先保存内容，关闭本应用所有页面，再重新打开。

离线缓存只包含固定清单中的公开静态资源，不缓存配置、密钥、Gist 响应或 `see/` 文件。恢复联网不会触发自动同步或留言轮询。

更多维护说明见 [OFFLINE.txt](OFFLINE.txt)。

## 本地开发

正常访问已部署网站不需要安装开发工具。修改项目时，需要 Node.js 和 pnpm；重新下载第三方资源的脚本还要求 Node.js 支持全局 `fetch`。

```sh
pnpm install --frozen-lockfile
pnpm run build
```

构建会生成主页的 Tailwind CSS，并更新离线资源的版本与哈希清单。已生成的运行资源随项目保存。

本地预览需要静态 HTTP 服务。例如，安装 Python 3 后，在项目根目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

然后打开 [本机预览](http://localhost:8000/pagemain.html)。`localhost` 地址只供当前设备访问；手机使用离线功能时，应访问部署后的 HTTPS 网站。

### 构建命令

| 命令 | 用途 |
| --- | --- |
| `pnpm run build` | 生成主页 CSS，并重建离线清单 |
| `pnpm run build:css` | 只生成主页 CSS，不更新离线清单 |
| `node scripts/build-offline.mjs` | 根据当前资源重建离线清单 |
| `pnpm run vendor:offline` | 重新下载固定版本的公开图表、图标字体及许可文件 |

**修改缓存范围内的 HTML、CSS、JS、字体或 `sw.js` 后，必须重新构建。** 发布时将这些资源和 `assets/js/offline-manifest.js` 一起更新。只运行 `build:css` 后直接发布，会导致离线资源校验不一致。

README 不在离线缓存清单中，单独修改本说明无需重建缓存。

## 测试

运行配置、留言逻辑和本地保存的单元测试：

```sh
pnpm run test:unit
```

浏览器测试还需要 Playwright 和 Chromium 或 Edge。当前测试的默认路径来自开发环境，其他机器需要设置 `PLAYWRIGHT_PATH` 和 `BROWSER_EXECUTABLE`。

以下为 PowerShell 示例，请先将路径替换为本机实际位置：

```powershell
$env:PLAYWRIGHT_PATH = 'C:\path\to\node_modules\playwright'
$env:BROWSER_EXECUTABLE = 'C:\path\to\msedge.exe'

node tests/feedback-ui.test.cjs
node tests/page6.test.cjs
node tests/offline.test.cjs
node tests/mobile-ui.test.cjs
```

测试使用合成数据并模拟远程 API，不读取真实凭据或修改真实 Gist。离线测试使用真实 Service Worker，覆盖断网重开、本地增删改、存储失败、缓存修复和版本更新。截图输出到 `tests/artifacts/`，不提交到仓库。

手机界面测试覆盖 320px、390px 窄屏、按钮尺寸、主题和弹窗焦点，并模拟键盘改变可见视口；模拟测试不能替代 iOS、Android 真机键盘验证。

## 发布与凭据

项目可以作为静态站点部署。发布前运行构建及与改动相关的测试，并检查暂存文件清单。

以下内容不应上传或作为站点内容发布：

- `see/`、`.publish-timer/`、`.idea/`、`node_modules/`。
- `tests/artifacts/` 中的截图、临时验证文件和发布辅助文件。
- 环境配置文件、PAT、AI 凭据、作者私钥或包含这些内容的备份。

`.gitignore` 已包含对应排除规则，但它不能替代提交前检查，也不会自动移除曾经被跟踪的文件。第三方资源的许可说明见 [assets/vendor/README.txt](assets/vendor/README.txt)，发布时保留相关许可文件。

## 当前边界

- 适合个人使用，尚未提供多用户账号和权限隔离。
- `index.html` 是伪装入口，不是真正的登录验证；当前首次设置的入口密码还会作为搜索词发送，请勿使用真实账户密码。
- 浏览器内保存的凭据未加密，离线缓存排除凭据不代表浏览器存储本身已加密。
- 云端记录仍按整份 `records.json` 保存，旧页面与其他设备同时操作可能互相覆盖，尚无完善的冲突合并。
- 时长分析根据本地和云端记录的时间关系推断配对，漏打或补打可能影响结果。
- 目前离线保证只覆盖主页功能，其他页面的资源和移动端体验仍可继续完善。
